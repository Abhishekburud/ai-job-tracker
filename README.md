# 🚀 AI Job Tracker

A full-stack AI-powered job tracking web application that helps users search jobs, analyze resume match, and track applications in one place.

---

## ✨ Features

- 🔍 Real-time job search (Adzuna API)
- 📄 Resume upload & parsing (PDF)
- 🎯 Smart match score (based on skills)
- 📊 Application tracking system
- 🤖 AI-like search (no paid API required)
- 🎨 Modern UI with Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Fastify
- Adzuna API
- pdf-parse

## ⚙️ Setup Instructions

### 🔹 1. Clone the repo
git clone https://github.com/YOUR-USERNAME/ai-job-tracker.git

cd ai-job-tracker
-------------------------------------------------------------------------------------------------------------------------

---

### 🔹 2. Setup Backend
cd backend
npm install
node server.js
-------------------------------------------------------------------------------------------------------------------------

---

### 🔹 3. Setup Frontend
cd frontend/ai-job-tracker
npm install
npm run dev
-------------------------------------------------------------------------------------------------------------------------

---

##  4. 🔐 Environment Variables

Create `.env` inside backend:
PORT=3000
ADZUNA_APP_ID=your_app_id
ADZUNA_APP_KEY=your_app_key

fpr this you have to create account on https://www.adzuna.com/ and then access api id and api key.....
